## myWeather
Weather application using JavaFX and SceneBuilder.

### Features
- Current weather (temperature, “feels like”, humidity, cloud coverage, precipitation/snow, time, AQI)
- 3 days weather forecast
- Weather of last 7 days
- Ability of look up the weather of any city
- HTTP requests to call the specified WeatherAPI endpoints
- Parsing JSON responses
- Offer feedback for loading states and error conditions
- Has both dark and light mode
